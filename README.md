# 🤖🌐 DevBase — База знаний для сайтов и ботов

Библиотека готовых, проверенных решений для быстрой сборки **ботов** (Telegram, Instagram, MAX)
и **сайтов**. Нейросеть (или человек) берёт готовый модуль/шаблон, копирует и дополняет под задачу —
вместо написания с нуля.

## 🎯 Идея

> Появилась задача → находим готовое решение в базе → копируем → дополняем/редактируем.

Каждый модуль:
- **самодостаточен** — минимум скрытых зависимостей;
- **документирован** — есть `README.md` с назначением, зависимостями и точками расширения;
- **единообразен** — общий стиль, конфиг и слой БД во всех модулях одного стека;
- **проверен** — рабочий пример использования.

## 🗂 Структура репозитория

```
devbase/
├── KNOWLEDGE_BASE.md      # 📖 МАНИФЕСТ: карта всех решений (читать первым)
├── bots/                  # 🤖 База ботов
│   ├── python/            #    стек Python (aiogram / async)
│   │   ├── core/          #    общее ядро: конфиг, БД, логи, i18n
│   │   ├── modules/       #    подключаемые модули: admin, stats, broadcast...
│   │   ├── platforms/     #    адаптеры платформ: telegram, instagram, max
│   │   └── templates/     #    готовые боты «под ключ»
│   └── node/              #    стек Node.js (grammY / TypeScript) — зеркало python
├── sites/                 # 🌐 База сайтов (следующий этап)
└── docs/                  # 📚 общие гайды и соглашения
```

## 🚀 Быстрый старт

Смотри `KNOWLEDGE_BASE.md` — там карта всех готовых решений с описанием, когда что брать.

Для конкретного стека:
- Python-боты: [`bots/python/README.md`](bots/python/README.md)
- Node-боты: [`bots/node/README.md`](bots/node/README.md)

## 🧭 Как этим пользуется нейросеть

1. Читает `KNOWLEDGE_BASE.md` — находит подходящий модуль/шаблон по тегам и задаче.
2. Открывает `README.md` нужного модуля — узнаёт зависимости и точки расширения.
3. Копирует модуль/шаблон в проект пользователя.
4. Дополняет и редактирует под конкретную задачу.
