# Данные бизнеса для шаблона `event`

Заполните поля в `config.js`. Плейсхолдер в квадратных скобках показывает, что нужно получить от бизнеса.
После замены удалите `demo: true` у записи.

## Обязательно

| Данные | Поле `config.js` |
|---|---|
| [НАЗВАНИЕ] агентства | `brand.name`, `brand.logoText` |
| [ОПИСАНИЕ] в одном предложении | `brand.description`, `seo.description` |
| [ГОРОД] | `contacts.city` |
| [ТЕЛЕФОН], [ПОЧТА] или [TELEGRAM] — хотя бы один | `contacts.phone`, `contacts.email`, `contacts.telegram` |
| [ЧАСЫ РАБОТЫ] | `contacts.hours` |
| [ЗАГОЛОВОК ПЕРВОГО ЭКРАНА] без «лучший» и «№ 1» | `hero.title`, `hero.text` |
| [ФОРМАТЫ], с которыми работает агентство | `formats` |
| [УСЛУГИ] и [ЦЕНЫ]: точная, «от», диапазон или «по запросу» | `services[].price` |
| [ТАРИФЫ СМЕТЫ] или решение не показывать смету | `pricing.formats`, `pricing.mode` |
| [ВАРИАНТЫ БЮДЖЕТА] | `pricing.budgets` |
| [ЮРИДИЧЕСКОЕ ЛИЦО], [ИНН], [ОГРН], [ЮРИДИЧЕСКИЙ АДРЕС] | `legal.operator`, `legal.inn`, `legal.ogrn`, `legal.address` |
| [ПОЧТА ДЛЯ ЗАПРОСОВ ПО ДАННЫМ], [АДРЕС САЙТА], [ДАТА ПОЛИТИКИ] | `legal.email`, `legal.site`, `legal.effectiveDate` |
| Подтверждение юриста по текстам документов | `legal.approved: true` |
| [АДРЕС САЙТА] для canonical | `seo.canonical` |

## Рекомендуется

| Данные | Поле |
|---|---|
| [ПРОЕКТЫ]: задача, состав работ, формат, фото с правом публикации | `portfolio` |
| [КОМАНДА]: имена и фото только с согласия сотрудников | `team` |
| [ОТЗЫВЫ] с источником и ссылкой | `reviews` |
| [ВОПРОСЫ И ОТВЕТЫ] | `faq` |
| [СЕРВИСЫ ОБРАБОТКИ ДАННЫХ]: Telegram, CRM | `legal.processors` |
| [ЛОГОТИП] | файл в `img/`, запись в `assets`, `brand.logo` |
| [СЧЁТЧИК МЕТРИКИ] | `integrations.analytics.yandexMetrika` |

## Фото

- Замените стоковые фото в `img/` фотографиями событий агентства.
- Для каждого файла заполните `assets`: `src`, `width`, `height`, `alt`, `source`, `author`, `license`.
- Публикуйте фото гостей только с разрешения.

## Нельзя

- Выдумывать сроки ответа, скидки, гарантии, число клиентов и награды.
- Оставлять демо-проекты как реальные кейсы.
- Класть токены Telegram и CRM в `config.js`.
