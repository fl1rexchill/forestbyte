# 🔌 Интеграции с CRM

Готовый код для отправки заявок (лидов) с сайта в CRM + пошаговые туториалы подключения.

## Что поддерживается

| CRM | Сложность подключения | Папка |
|-----|----------------------|-------|
| **Bitrix24** | 🟢 очень просто (входящий вебхук — одна ссылка) | `bitrix24/` |
| **amoCRM** | 🟡 средне (нужен долгосрочный токен интеграции) | `amocrm/` |

Каждая папка содержит:
- `*.php` — класс для PHP-сайтов и WordPress-плагина;
- `*.js` — модуль для Node.js-сайтов;
- `TUTORIAL.md` — **пошаговая инструкция подключения «на пальцах»**.

## Единый смысл

Все адаптеры делают одно: берут данные формы (имя, телефон, e-mail, комментарий)
и создают **лид** (заявку) в CRM. Данные вводишь один раз в настройках —
дальше форма шлёт заявки автоматически.

```
Форма на сайте  →  адаптер CRM  →  Лид в Bitrix24 / amoCRM
```

## С чего начать

1. Выбери свою CRM (если её нет — заведи бесплатный аккаунт).
2. Открой `TUTORIAL.md` в её папке и пройди шаги — получишь ключ/ссылку.
3. Вставь ключ в настройки (WordPress-плагин `Forestbyte → Настройки → CRM`,
   либо в конфиг своего сайта).
4. Готово — заявки с форм пойдут в CRM.

> Не знаешь, какую выбрать? Возьми **Bitrix24** — подключается за 2 минуты одной ссылкой.
