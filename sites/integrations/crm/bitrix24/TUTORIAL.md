# 📘 Как подключить Bitrix24 — по шагам (для новичка)

Цель: получить одну секретную ссылку (**входящий вебхук**), через которую сайт будет
класть заявки в вашу CRM. Займёт ~3 минуты.

> Вам НЕ нужно ничего программировать. Нужно только скопировать одну ссылку.

## Шаг 1. Войдите в свой Bitrix24
1. Откройте ваш портал: `https://ВАШ-ПОРТАЛ.bitrix24.ru` (или .by/.kz/.com).
2. Войдите под аккаунтом администратора.

## Шаг 2. Откройте раздел разработчика
1. Слева в меню нажмите **«Приложения»** (иконка с квадратиками).
   - Если такого пункта нет — нажмите **«Ещё»** внизу меню и найдите **«Разработчикам»**.
2. Выберите **«Другое»** → **«Входящий вебхук»**.
   (Полный путь: *Приложения → Разработчикам → Другое → Входящий вебхук*.)

## Шаг 3. Дайте вебхуку права
1. Откроется окно с настройкой прав доступа.
2. В списке **«Настройка прав»** поставьте галочку напротив **CRM (crm)**.
3. Нажмите **«Сохранить»**.

## Шаг 4. Скопируйте ссылку
1. После сохранения появится **«Вебхук для вызова rest api»** — длинная ссылка вида:
   ```
   https://ВАШ-ПОРТАЛ.bitrix24.ru/rest/1/abcd1234efgh5678/
   ```
2. **Скопируйте её целиком.** Это и есть ваш ключ. Никому не показывайте.

## Шаг 5. Вставьте ссылку в сайт
- **WordPress:** админка → **Forestbyte → Настройки → CRM** → выберите «Bitrix24» →
  вставьте ссылку в поле **«Webhook URL»** → **Сохранить**.
- **Свой сайт (PHP):** откройте `bitrix24.php` и передайте ссылку в конструктор
  `new ForestbyteBitrix24("ССЫЛКА")` (или через переменную окружения `BITRIX24_WEBHOOK`).
- **Свой сайт (Node):** переменная окружения `BITRIX24_WEBHOOK=ССЫЛКА`.

## Шаг 6. Проверьте
1. Отправьте тестовую заявку через форму на сайте.
2. В Bitrix24 откройте **CRM → Лиды** — там должна появиться новая заявка.

Готово! 🎉

---

### Если что-то пошло не так
- **Лид не появился** — проверьте, что в правах вебхука стоит галочка **CRM**.
- **Ошибка 401 / «Invalid request credentials»** — ссылку скопировали не полностью
  (в конце должна быть `/`).
- **Заявка без телефона** — проверьте, что поле формы называется `phone` (см. код адаптера).
