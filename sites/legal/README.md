# ⚖️ Юридические шаблоны (152-ФЗ)

Готовые шаблоны документов для сайтов, работающих с персональными данными граждан РФ.

> ⚠️ **Дисклеймер:** это шаблоны для быстрого старта, а не юридическая консультация.
> Перед публикацией замените плейсхолдеры и дайте проверить юристу под вашу
> конкретную деятельность. Ответственность за соответствие закону — на владельце сайта.

## Файлы

| Файл | Что это | Когда обязателен |
|------|---------|-----------------|
| `privacy-policy-152fz.md` | Политика в отношении обработки ПД | Всегда, если есть любые формы/аналитика |
| `consent-personal-data.md` | Согласие на обработку ПД | При сборе ПД через формы |
| `cookie-policy.md` | Политика использования cookie | При использовании cookie/аналитики |

## Плейсхолдеры (заменить во всех файлах)

| Плейсхолдер | Значение |
|-------------|----------|
| `{{ОПЕРАТОР}}` | Наименование/ФИО оператора (ООО «...», ИП ...) |
| `{{ИНН}}` | ИНН оператора |
| `{{АДРЕС}}` | Юридический адрес |
| `{{САЙТ}}` | Адрес сайта (example.ru) |
| `{{EMAIL}}` | Контактный e-mail для запросов по ПД |
| `{{ТЕЛЕФОН}}` | Контактный телефон |
| `{{ДАТА}}` | Дата вступления в силу |

Быстрая замена (пример, PowerShell):
```powershell
(Get-Content privacy-policy-152fz.md) -replace '{{САЙТ}}','example.ru' | Set-Content privacy-policy-152fz.md
```

## Как связать с сайтом

- ссылку на политику дают: футер (`<fb-footer>` колонка «Документы»),
  баннер cookie (`<fb-cookie-consent policy-href="/privacy">`), все формы (чекбокс согласия);
- обязателен чекбокс согласия у форм: «Я согласен с [политикой] и даю согласие на обработку ПД».
