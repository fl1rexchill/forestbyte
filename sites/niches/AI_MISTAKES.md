# Ошибки, которые ИИ допускает при создании сайтов — и как их не допустить

Сводка из разборов «AI slop»-дизайна и аудитов сайтов, собранных нейросетями
(источники — в конце), плюс ошибки, которые мы сами ловили при сборке. Каждый сайт
в `sites/niches/` проверяется по чек-листу в конце файла.

---

## 1. Визуальные «следы ИИ»

| Ошибка | Почему плохо | Как делаем мы |
|---|---|---|
| Inter/системный шрифт везде | Сайт выглядит «как все», без характера | У каждой ниши своя пара шрифтов (serif + гротеск, узкий дисплейный и т.д.) |
| Фиолетово-синие градиенты | Главный маркер ИИ-дизайна | Фиолетовый запрещён. Палитра от ниши: тёплый беж, тёмно-зелёный + красный, чёрный + жёлтый |
| Одинаковые карточки, `border-radius: 16px` у всего | Нет иерархии, глазу не за что зацепиться | Разные размеры, «лесенка», bento, крупные акценты |
| Гигантский hero с общим заголовком «Build the future» | Посетитель за 5 секунд не понимает, что тут продают | Заголовок = результат + район + срок/цена |
| Иконки-эмодзи и одинаковые «три колонки с иконками» | Шаблонно | Цифры, фото, реальные параметры услуги |
| Эффекты ради эффектов: параллакс везде, свой курсор, фоновые анимации | Мешает читать, тормозит на телефоне | Анимация объясняет: появление, смена состояния, отклик кнопки |
| Нет микро-взаимодействий | Кнопки «мёртвые», форма не отвечает | hover/active у кнопок, состояния загрузки, ошибок, успеха |

## 2. Тексты

| Ошибка | Как делаем мы |
|---|---|
| Пустые слова: «лучшие», «инновационный», «best-in-class», «может помочь» | Конкретика: цена «от», длительность, время ответа, что входит |
| Lorem ipsum, «Ваш текст здесь», «Company Name» | Все тексты написаны под нишу на русском |
| Неподтверждённые обещания и медицинские гарантии | Косметология и ветеринария: без диагнозов и гарантий результата |
| Выдуманная статистика «100 000 клиентов» | Цифры скромные и правдоподобные, помечены как демо в README |
| Англицизмы и машинный перевод в интерфейсе | Единый русский язык, «ё» не ломаем, типографика: «ёлочки», неразрывные пробелы перед «₽» |
| Устаревший год в подвале | Год подставляется из JS (`new Date().getFullYear()`) |

## 3. Функциональность («кнопка есть — функции нет»)

| Ошибка | Как делаем мы |
|---|---|
| Кнопки и ссылки, ведущие на `#` | Каждая кнопка открывает форму, прокручивает к блоку или выполняет действие |
| Форма показывает «Успешно!», но ничего не отправляет | Заявка уходит на `/api/lead` (Node-сервер → Telegram + CRM). Без сервера — честный демо-режим с сохранением в браузере и номером заявки |
| Ошибка сети = тишина или вечный спиннер | Таймаут, текст ошибки и запасной контакт (телефон/Telegram) |
| Нет валидации или она только на `required` | Проверка телефона/имени/дат, подсветка поля, сообщение рядом с полем, фокус на первом ошибочном поле |
| Двойная отправка по двойному клику | Кнопка блокируется на время отправки |
| Нет защиты от спама | Honeypot-поле + минимальное время заполнения + лимит на сервере |
| Калькулятор с захардкоженным результатом | Цена считается из справочника услуг, меняется при каждом изменении параметра |
| Бронирование позволяет выбрать прошедшую дату или занятый слот | Прошлое заблокировано, занятые слоты берутся с сервера / из сохранённых заявок |
| Корзина теряется при перезагрузке | Корзина, избранное, черновики — в `localStorage` с try/catch |
| Загрузка файла без ограничений | Проверка типа и размера, превью, удаление файла |
| Модалка, которую нельзя закрыть Esc, скролл под ней продолжает ехать | Esc, клик по фону, возврат фокуса, блокировка скролла (`lenis.stop()`) |
| Мобильное меню не закрывается после клика по пункту | Закрывается, `aria-expanded` обновляется |

## 4. Плавный скролл и анимации

| Ошибка | Как делаем мы |
|---|---|
| Smooth scroll ломает якоря, фиксированную шапку и модалки | Lenis с `anchors` и `offset` под высоту шапки; в модалках `data-lenis-prevent` |
| Нет учёта `prefers-reduced-motion` | При reduced-motion Lenis не запускается, анимации появляются сразу |
| Контент скрыт через `opacity:0` и появляется только из JS | Если JS/библиотека не загрузились — контент виден (класс `js` ставится только при успешной инициализации) |
| Анимации `top/left/width` вместо `transform/opacity` | Анимируем только transform/opacity — без лагов |
| Бесконечный `requestAnimationFrame` и слушатели scroll без throttle | Один RAF-цикл Lenis, IntersectionObserver для появления |
| Прелоадер на 3 секунды | Прелоадер максимум ~1 c и только там, где он часть стиля референса |
| Библиотеки с CDN: CDN упал — сайт мёртв | Lenis и anime.js лежат локально в `_shared/vendor/` |

## 5. Адаптив

| Ошибка | Как делаем мы |
|---|---|
| Горизонтальный скролл на телефоне | `overflow-x: clip` на body, проверка на 375px |
| `100vh` прыгает в мобильном Safari | `100svh`/`100dvh` |
| Мелкие тапы (< 44px) | Все интерактивные элементы ≥ 44px |
| Hover-эффекты — единственный способ увидеть информацию | На тач-устройствах та же информация видна без hover |
| Таблицы цен ломают вёрстку | Горизонтальный скролл внутри контейнера или карточки на мобильном |
| Фикс-панели закрывают контент | Нижняя CTA-панель на мобильном учитывается в `padding-bottom` |

## 6. Доступность

| Ошибка | Как делаем мы |
|---|---|
| `div` вместо `button`, клики без клавиатуры | Нативные `button`, `a`, `input`, `label` |
| Нет `alt` у картинок | У всех содержательных фото — описательный `alt`, декоративные — `alt=""` |
| Пропуски уровней заголовков, несколько `h1` | Один `h1`, дальше `h2`/`h3` по порядку |
| Убран outline фокуса | Видимый `:focus-visible` |
| Контраст текста на фото | Затемняющий градиент под текстом |
| Ошибки формы только цветом | Текст ошибки + `aria-invalid` + `aria-describedby` |
| Табы/аккордеоны без ARIA | `aria-selected`, `aria-controls`, `aria-expanded` |

## 7. Техническое

| Ошибка | Как делаем мы |
|---|---|
| Хотлинк картинок с чужих сайтов, «выдуманные» ссылки на фото (404) | Фото CC0 скачаны и лежат в `img/` сайта в webp, проверены визуально |
| Гигантские изображения | Макс. 1400px, webp ~80–200 КБ, `loading="lazy"` ниже первого экрана, `width/height` против прыжков вёрстки |
| Ошибки в консоли | Каждый сайт проверяется в браузере: 0 ошибок в консоли |
| Весь код в одном файле на 3000 строк | `index.html` + `style.css` + `app.js`, общее ядро в `_shared/core.js` |
| Смешение стилей имён, мёртвый код | Единые соглашения, без неиспользуемых функций |
| `localStorage` без try/catch | Приватный режим Safari не ломает сайт |
| Секреты (токен бота) во фронтенде | Токен только в `.env` сервера |
| Сайт не открывается без сборки | Чистый HTML/CSS/JS: работает и через сервер, и просто двойным кликом |

## Чек-лист приёмки сайта

- [ ] Предложение понятно за 5 секунд: что, где, почём, как быстро
- [ ] Ни одной «мёртвой» кнопки/ссылки
- [ ] Основной сценарий (запись / расчёт / заказ) проходится до конца без помощи
- [ ] Форма: валидация, блокировка повторной отправки, состояние загрузки, ошибка, успех с номером заявки
- [ ] Заявка приходит на сервер и в Telegram (при запуске через `server/`)
- [ ] Плавный скролл, якоря с учётом шапки, модалки не прокручивают фон
- [ ] `prefers-reduced-motion` уважается
- [ ] 375px: нет горизонтального скролла, всё нажимается
- [ ] Клавиатура: Tab проходит по всем элементам, Esc закрывает модалки
- [ ] 0 ошибок в консоли, все изображения загружаются
- [ ] Без фиолетового, без Lorem ipsum, без «Company Name»

## Пойманные при сборке этих сайтов (добавлено по ходу проверки)

- **`backdrop-filter` или `transform` на шапке** превращают её в контейнер для `position: fixed` — полноэкранное мобильное меню внутри шапки схлопывается до её высоты. Снимаем эти свойства, пока меню открыто.
- **Разбивка заголовка на слова по `\s`** рвёт неразрывные пробелы («0&nbsp;₽» уезжает на новую строку). Делим только по обычным пробелам.
- **Общая панель у нескольких табов**: цикл «спрятать все, кроме выбранного» прячет панель, если её `id` один на всех. Сначала прячем все, потом показываем выбранную.
- **Маска телефона и «8»**: после автоподстановки «+7» пользователь по привычке набирает «8…» — это код страны, а не цифра номера.
- **Кэш JS/CSS на время разработки**: `max-age` на скриптах = правки «не применяются». Для кода — `no-cache` + `Last-Modified`.
- **Большие версии фото с фотостоков бывают с водяным знаком** (rawpixel `image_1300`), хотя превью чистое — каждое итоговое фото проверяем глазами.
- **Grid/flex-элементы с `min-width: auto`**: длинное поле ввода, кнопка с `nowrap` или таблица распирают колонку, и страница на телефоне становится шире экрана. Ставим `min-width: 0` и `minmax(0, 1fr)`.
- **Фраза, склеенная неразрывными пробелами, в огромном шрифте** («которой&nbsp;вы&nbsp;доверяете» на 52px) не помещается в 375px. Неразрывные пробелы — только для коротких связок (предлог + слово, число + ₽).
- **Правило для `span` внутри блока цифры** (`.stats span {font-size:15px}`) задевает и сам счётчик внутри `<b><span>` — цифра становится мелкой. Используем дочерний селектор `>`.
- **Демо-статусы без бэкенда**: «Статус заказа» в демо-режиме честно пишет, что статусы меняются в CRM при запуске сервера, а не рисует фейковый прогресс.
- **Фото «до/после» в медицине и косметологии**: не публикуем сгенерированные или обработанные «результаты» — это и обман, и нарушение правил рекламы медуслуг.
