# Карта переиспользования

Что взято из базы, откуда и что изменено. Источник истины — код; если README базы расходится с кодом, в таблице указан код.

## Требование → существующее решение → изменение

| Требование | Существующее решение в базе | Изменение в шаблонах |
|---|---|---|
| Общее ядро, формы, модальные окна | `sites/niches/_shared/core.js`: `FB.form`, `FB.modal`, `FB.validate`, `FB.tabs`, `FB.accordion`, Lenis | Скопировано в `_shared/core.js`. Второй механизм форм и модальных окон не создавался. |
| Совместимость с `window.SITE` | Ядро читает `window.SITE = { site, name, phone, telegram, endpoint }` | Ядро собирает `window.SITE` из `window.SITE_CONFIG` (`config.js`), если `window.SITE` не задан. |
| Демо-режим без отправки наружу | Ядро уходит в демо, если нет `http(s)` или сервер отвечает 404 | Режим задаёт `meta.mode`. `demo` — только `localStorage`. `production` — только сервер; ошибка сервера показывается как ошибка, без тихого сохранения в браузере. Добавлен `server-test` для localhost. |
| Честное сообщение об успехе | «Заявка принята. Скоро свяжемся!» | «Демо-заявка сохранена на этом устройстве» в демо; «Тестовая заявка сохранена на сервере» в `server-test`; текст успеха из `booking` в рабочем режиме. |
| Не показывать выдуманную занятость | `FB.lead.busy` добавлял псевдослучайные занятые слоты (`FB.seeded`) | `FB.lead.busy`, `FB.seeded`, `FB.isPastSlot`, `FB.lead.status` удалены. Все шаблоны — заявки с «Желаемым временем». |
| Защита от ботов | Honeypot + время заполнения; при быстрой отправке ядро показывало «Заявка принята» | Honeypot сохранён. При слишком быстрой отправке форма просит нажать кнопку ещё раз, а не сообщает ложный успех. |
| Проверка полей | Правила `required name phone email contact min:N` | Добавлены `num` (число в пределах `min`/`max`) и `future` (дата не в прошлом). |
| Кнопки без контакта | `data-phone`, `data-tg` всегда получали ссылку (`#`, если контакта нет) | Нет контакта — кнопка скрыта. |
| Сервер заявок | `sites/niches/server/server.mjs` | Скопирован в `server/server.mjs` с изменениями ниже. |
| Список сайтов и префиксы | Сервер брал `site` и `prefix` из запроса | Сервер читает `config.js` каждой папки при старте. Неизвестный `site` — 422. Префикс номера берётся из конфигурации; дубли `site` и `prefix` отклоняются при старте. |
| Серверная проверка | Проверялся только контакт | Проверяются согласие, имя, контакт, тип заявки, формат даты, `Content-Type`, размер и тип вложений. |
| Лимит частоты | 8 заявок за 10 минут, IP из `X-Forwarded-For` без условий | IP из заголовка — только при `TRUST_PROXY=1`. Лимит настраивается `RATE_LIMIT`. |
| Сохранение до ответа | Ошибка записи терялась в `persist()` | Ошибка записи возвращает 500. «Принято» — только после записи на диск. |
| Сохранение и доставка — разные вещи | Уведомление отправлялось без записи результата | Поле `delivery` (`off`, `pending`, `sent`, `failed`, `skipped-test`) хранится в заявке и видно в CRM. Демо-сайты уведомления не отправляют. |
| Лишние публичные методы | `GET /api/busy`, `GET /api/lead/:id`, отмена и перенос по номеру | Не перенесены: у шаблонов нет рабочего сценария бронирования и статуса ремонта. Добавлен `GET /api/health`. |
| Доступ к CRM | Сравнение токена строкой | `crypto.timingSafeEqual`. Без `ADMIN_TOKEN` панель закрыта. |
| Статика и индексация | Запрет `server/` и `data/` | Дополнительно закрыты файлы с точкой. Демо-сайты, CRM и оглавление отдаются с `X-Robots-Tag: noindex`. Заголовки `Referrer-Policy`, `X-Frame-Options`. |
| CRM-панель | `sites/niches/crm/index.html` | Скопирована в `crm/`. Названия сайтов приходят с сервера. Добавлены типы заявок шаблонов, блок «Сохранение и доставка», метка «тест», проверка сервера через `/api/health`. Шрифт Inter с Google Fonts заменён системным. |
| Баннер cookie | `sites/components/cookie-consent/fb-cookie-consent.js` (ES-модуль, Shadow DOM, `--fb-*`) | Копия в `_shared/components/cookie-consent/`: аналитика и маркетинг не отмечены заранее; убрано «продолжая пользоваться сайтом…»; `storage-key` на сайт; обычный `<script>` для работы через `file://`; кнопки 44 px. Темизация через `--fb-*` в `style.css` ниши. |
| Аналитика после согласия | Пример в `sites/components/README.md` | `site.js` запускает Яндекс Метрику только после согласия на аналитические cookie и только в `production`. |
| FAQ | `sites/components/faq/fb-faq.js` и `FB.accordion` в ядре | Использован `FB.accordion`: второй механизм аккордеона не нужен, ES-модуль не работает через `file://`. |
| Юридические документы | `sites/legal/*.md` (плейсхолдеры `{{ОПЕРАТОР}}` и др.) | `_shared/legal.js` собирает три страницы из `config.legal`. Незаполненное поле видно как `[ПЛЕЙСХОЛДЕР]`. Пока `legal.approved !== true`, страница показывает предупреждение. |
| CRM-адаптеры | `sites/integrations/crm/bitrix24/bitrix24.js`, `amocrm/amocrm.js` (`createLead`) | Подключаются сервером по пути `../../../integrations/crm/...`, только если заданы ключи в `.env`. Код адаптеров не менялся. |
| Библиотеки | `sites/niches/_shared/vendor/` Lenis 1.3.26, anime.js 4.5.0 | Скопированы без изменений. Лицензии — `_shared/vendor/LICENSES.md`. |
| Шрифты | Сайты базы грузили Google Fonts по ссылке | Шрифты лежат локально в `_shared/fonts/` с текстами OFL. |
| Изображения | `sites/niches/*/img/*.webp`, в README — «Openverse CC0», без источника каждого файла | Не переиспользованы: лицензию каждого файла нельзя проверить. Новые фото CC0 скачаны с WordPress Photo Directory и StockSnap через Openverse; лицензия проверена на странице источника; сведения — в `config.assets` и `img/CREDITS.md`. |

## Адаптация исходных сайтов

| Шаблон | Исходный сайт | Что сохранено | Что изменено |
|---|---|---|---|
| `auto/` | `sites/niches/auto/` (ТОРК) | Марка → класс → коэффициент цены работ; корзина работ; расчёт в `localStorage` | Справочники перенесены в `config.js`; работа и запчасти раздельно; поиск; «Не знаю, какая услуга нужна»; «Желаемое время» вместо слотов; убраны гараж, статус ремонта и случайные допработы. |
| `cosmetology/` | `sites/niches/cosmetology/` (Этюд) | Каталог с карточкой процедуры; категории | Медицинские тексты исходного демо не перенесены. Карточка показывает описание, подготовку и ограничения только при `approved: true`. Убраны подбор процедуры по задаче, «Мой курс» и вопрос врачу. Специалисты вынесены на первый план. |
| `beauty/` | `sites/niches/beauty/` (Пудра) | Корзина визита из нескольких услуг; мастера по услугам; портфолио | Убраны расписание со случайными сменами, филиалы, кабинет, сертификаты и абонементы с оплатой. Добавлены правила совместимости и консультация перед сложным окрашиванием. |
| `event/` | Нет своего сайта в базе | — | Новая структура. Кейтеринг — только необязательная услуга, `sites/niches/catering/` не использован как основа. |
| `detailing/` | Нет своего сайта в базе | — | Новая структура, отдельная от автосервиса. |
