# Данные бизнеса для шаблона `auto`

Заполните поля в `config.js`. После замены удалите `demo: true` у записи.

## Обязательно

| Данные | Поле `config.js` |
|---|---|
| [НАЗВАНИЕ] сервиса | `brand.name`, `brand.logoText` |
| [ОПИСАНИЕ] | `brand.description`, `seo.description` |
| [ГОРОД], [АДРЕС], [ЧАСЫ РАБОТЫ], [КАРТА] | `contacts.city`, `contacts.address`, `contacts.hours`, `contacts.map.url` |
| [ТЕЛЕФОН], [ПОЧТА] или [TELEGRAM] — хотя бы один | `contacts.*` |
| [МАРКИ] и [КЛАССЫ] с коэффициентами | `carBrands`, `carClasses` |
| [РАБОТЫ]: название, длительность, [ЦЕНА РАБОТЫ], [ЦЕНА ЗАПЧАСТЕЙ] | `services` |
| [УСЛОВИЯ СОГЛАСОВАНИЯ ДОПРАБОТ] — утверждённый текст | `policies.extraWork` |
| [ЮРИДИЧЕСКОЕ ЛИЦО], [ИНН], [ОГРН], [ЮРИДИЧЕСКИЙ АДРЕС] | `legal.operator`, `legal.inn`, `legal.ogrn`, `legal.address` |
| [ПОЧТА ДЛЯ ЗАПРОСОВ ПО ДАННЫМ], [АДРЕС САЙТА], [ДАТА ПОЛИТИКИ] | `legal.email`, `legal.site`, `legal.effectiveDate` |
| Подтверждение юриста по текстам документов | `legal.approved: true` |

## Рекомендуется

| Данные | Поле |
|---|---|
| [ГАРАНТИЯ] на работы из договора | `policies.warranty` |
| [ПОРЯДОК РАБОТЫ СО СВОИМИ ЗАПЧАСТЯМИ] | `policies.parts` |
| [ЭТАПЫ ВИЗИТА] | `visit` |
| [ОТЗЫВЫ] с источником | `reviews` |
| [ВАРИАНТЫ ЧАСТИ ДНЯ] | `booking.dayParts` |

## Фото

- Замените стоковые фото фотографиями сервиса: боксы, оборудование, приёмка.
- Скрывайте госномера и лица клиентов.

## Нельзя

- Показывать выдуманную занятость постов или готовность ремонта.
- Обещать сроки ремонта без данных сервиса.
