# Автосервис — `auto/`

Адаптация `sites/niches/auto/`.
Цель посетителя: выбрать работы или описать проблему и оставить заявку.
Главное действие: «Оставить заявку».

## Блоки страницы

Язык шаблона — технический чертёж и бланки автосервиса: тонкие линии, коды работ, моноширинные цифры, жёлтый как маркер.

1. Первый экран — лист чертежа на всю ширину: заголовок сверху, схема машины в центре (клик по узлу открывает раздел каталога), внизу слева пояснение и кнопка «Выбрать работы» (`hero.cta`), справа штамп чертежа — он же форма машины: марка, модель, год со своими выпадающими списками (марку можно искать по-русски) и госномер в виде номерного знака. В заголовке штампа — класс и коэффициент цены работ. Схема перерисовывается под кузов выбранной модели: седан, хэтчбек или кроссовер (`carBodies`); подпись «Кузов: …» — под схемой.
2. Работы и цены: прейскурант с кодами работ (`ТО-01`, `ТР-03`), поиск по названию и коду, квадратная кнопка «+» (в наряде — галочка). Варианты работы (радиус шин) — кнопками в строке. Вариант «Не знаю, какая услуга нужна».
3. Заказ-наряд (черновик) рядом с каталогом от ширины 900 px: только заполненные данные машины (марка, госномер, пробег, VIN), строки работ, работа и запчасти раздельно, итог и время. Пустой наряд — одна подсказка, без пустых строк.
4. Путь машины по сервису: этапы визита и что остаётся у клиента на каждом. Вместе с историей — одна тёмная глава.
5. История обслуживания: журнал записей на шкале пробега — машина, пробег, отзыв, работы с переходом в каталог. Демо-пометка одна на блок.
6. «Без мелкого шрифта»: условия крупно с выделением маркером слева, частые вопросы справа. На странице есть разметка FAQPage.
7. Заявка в 2 шага: заголовок и шаги слева, форма справа.
8. Контакты и карта (`contacts.map.embed`); в демо вместо карты — схема-заглушка.

Личного кабинета и статуса ремонта нет: у шаблона нет рабочего источника этих данных (`features.cabinet: false`, `features.repairStatus: false`).
Шаблон не генерирует дополнительные работы и готовность ремонта.

## Дизайн и анимации

- Roboto Condensed — заголовки; капсом только главный заголовок первого экрана и кнопки. Подписи, меню, вкладки — Golos Text обычным регистром.
- JetBrains Mono — только данные: коды работ, цены, время, пробег, VIN.
- Ширины: от 1200 px прейскурант в шесть колонок, 900–1199 — запчасти строкой под названием, до 900 — наряд под каталогом, на телефоне нижняя кнопка показывает число работ и сумму. Меню сворачивается в бургер до 860 px.
- Lenis и anime.js на странице не подключены: прокрутка нативная, анимации — CSS и Web Animations API.
- Схема прорисовывается один раз при загрузке, наведение на узел подсвечивает деталь и выноску.
- Новые строки наряда появляются сверху вниз, итог перещёлкивается к новой сумме, «В наряд» — плюс превращается в галочку.
- Маркер проводится по ключевой фразе условия, когда условие появляется на экране.
- При `prefers-reduced-motion` анимации отключены, всё видно сразу.
- Демо-пометки — одной строкой на блок (цены, отзывы, условия, контакты). Подсказка о незаполненных реквизитах — в консоли браузера.
- Системных элементов формы нет: свои выпадающие списки, выбор дня, сегменты времени суток и чекбоксы.

## Сценарий заявки

Машина и работы выбираются выше на странице, в заявке их не спрашиваем второй раз — они показаны сводкой.

1. «Машина и время»: марка (поле есть, только если марку не выбрали на первом экране), желаемый день — кнопки на две недели вперёд (выходные из `contacts.hours` недоступны), время суток. «Не знаю, какая услуга нужна» открывает поле описания проблемы.
2. «Контакт»: имя, телефон, госномер (подставляется из номерного знака), пробег, VIN, комментарий, согласие.

- Шаг 1 не пропускает дальше без работ в наряде или описания проблемы.
- Пробег — только цифры, VIN — латиница и цифры без I, O, Q; оба сразу попадают в наряд.
- После отправки — талон записи: номер заявки крупно и госномер.
- Тип заявки в CRM: `service_request`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `carClasses` | `{ A: { name, coef }, … }` | Классы и коэффициенты стоимости работ. |
| `carBrands` | `{ 'Марка': 'A' }` | Марка → класс. Марки нет в списке — цены работ «от» по базовому классу. |
| `carModels` | `{ 'Марка': ['Модель', …] }` | Список «Модель» по маркам. Клиент может вписать свою модель. |
| `carBrandAliases` | `{ 'Марка': 'слова через пробел' }` | Написания марки по-русски для поиска в списке «Марка». |
| `carBodies` | `{ hatch: ['Марка Модель', …], suv: [...] }` | Кузов модели для схемы на первом экране. Чего нет в списках — седан. |
| `categories[]` | `{ id, name, code, node, nodeLabel }` | Вкладки каталога. `code` — префикс кода работы. `node` — узел на схеме: `engine`, `dash`, `battery`, `brakes`, `suspension`, `wheel`; `nodeLabel` — подпись узла. |
| `services[]` | `{ id, cat, name, duration, labor, parts, partsNote, noCoef, variants[], demo }` | Работы. `labor` — стоимость работы, `parts` — запчасти (`null` — не нужны). `noCoef: true` — цена не зависит от класса. |
| `services[].variants[]` | `{ id, name, labor }` | Выбор внутри работы, например радиус шин. |
| `visit[]` | `{ title, text, gives }` | Этапы визита. `gives` — что остаётся на руках (строка «На руках»). |
| `policies` | `{ extraWork, parts, oldParts, warranty }` | Условия. Пустая строка скрывает пункт. |
| `policyMarks` | `{ extraWork, parts, oldParts, warranty }` | Фраза из текста условия, которую выделяет маркер. Должна точно входить в текст. |
| `reviews[]` | `{ text, author, car, mileage, works[], date, source, url, demo }` | История обслуживания. `mileage` — пробег числом, `works` — `id` работ из `services`. |
| `booking.dayParts[]` | строки | Варианты части дня. Текст после запятой выводится мелко: «Утро, до 12:00». |
| `contacts.hours[]` | `{ days, time }` | Часы работы. Дни со словом «выходной» в `time` недоступны в выборе дня. |
| `contacts.map` | `{ url, embed }` | `embed` — src виджета Яндекс Карт (Конструктор карт → «Получить код»), `url` — ссылка «Открыть карту». |
| `pricing.note` | строка | Пояснение под расчётом. |

## Как считается расчёт

- Работа = сумма `labor` × коэффициент класса (округление до 10 ₽). Без класса — «от» по базовым ценам.
- Запчасти = сумма `parts`, без коэффициента. Цена «по запросу» добавляет «+ N позиций по запросу».
- Итог = работа + запчасти. Итог — предварительный, окончательный — в заказ-наряде после приёмки.
- `hero.image` на странице не выводится (первый экран — схема), используется для `og:image`.

## Мобильная версия (до 760 px)

Та же информация, что на компьютере, но компактнее. Компьютер и планшет не меняются.

- Штамп машины на первом экране свёрнут в строку «Ваш автомобиль · выбрать» и раскрывается по нажатию; ссылки «Выбрать» в наряде раскрывают его.
- Вкладки каталога — одной строкой с прокруткой. Пустой наряд — только подсказка.
- История обслуживания листается вбок (карусель со счётчиком).
- Условия — крупно, как на компьютере; частые вопросы раскрываются по нажатию.
- Демо-плашка — одной строкой.

## Пример замены данных

```js
services: [
  { id: 'oil', cat: 'to', name: 'Замена масла', duration: 40, labor: { type: 'fixed', value: 1500 }, parts: { type: 'from', value: 4000 } },
  { id: 'diag-pc', cat: 'diag', name: 'Компьютерная диагностика', duration: 30, labor: { type: 'fixed', value: 1500 }, parts: null }
],
policies: { extraWork: 'Утверждённый текст о согласовании допработ.', parts: '', warranty: 'Текст гарантии из договора.' }
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js auto`.
