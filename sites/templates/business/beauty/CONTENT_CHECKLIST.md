# Данные бизнеса для шаблона `beauty`

Заполните поля в `config.js`. После замены удалите `demo: true` у записи.

## Обязательно

| Данные | Поле `config.js` |
|---|---|
| [НАЗВАНИЕ] салона | `brand.name`, `brand.logoText` |
| [ОПИСАНИЕ] | `brand.description`, `seo.description` |
| [ГОРОД], [АДРЕС], [ЧАСЫ РАБОТЫ] | `contacts.city`, `contacts.address`, `contacts.hours` |
| [ТЕЛЕФОН], [ПОЧТА] или [TELEGRAM] — хотя бы один | `contacts.*` |
| [КАТЕГОРИИ], которые есть в салоне | `categories` |
| [УСЛУГИ]: состав, длительность, [ЦЕНА] | `services` |
| [НЕСОВМЕСТИМЫЕ УСЛУГИ] | `compatibility.exclusive` |
| [МАСТЕРА] и услуги, которые выполняет каждый | `team[].services` |
| [ЮРИДИЧЕСКОЕ ЛИЦО], [ИНН], [ОГРН], [ЮРИДИЧЕСКИЙ АДРЕС] | `legal.operator`, `legal.inn`, `legal.ogrn`, `legal.address` |
| [ПОЧТА ДЛЯ ЗАПРОСОВ ПО ДАННЫМ], [АДРЕС САЙТА], [ДАТА ПОЛИТИКИ] | `legal.email`, `legal.site`, `legal.effectiveDate` |
| Подтверждение юриста по текстам документов | `legal.approved: true` |

## Рекомендуется

| Данные | Поле |
|---|---|
| [ИМЕНА И ФОТО МАСТЕРОВ] — с их согласия | `team[].name`, `team[].photo`, `assets` |
| [ПОРТФОЛИО]: фото работ, услуга, мастер; разрешение клиента на публикацию | `portfolio` |
| [УСЛУГИ С КОНСУЛЬТАЦИЕЙ] | `services[].consultFirst` |
| [ОТЗЫВЫ] с источником | `reviews` |
| [ВОПРОСЫ И ОТВЕТЫ] | `faq` |

## Фото

- Замените стоковые фото работами мастеров салона.
- Публикуйте лица клиентов только с их разрешения.

## Нельзя

- Показывать свободные окна без подключённого расписания.
- Включать сертификаты, абонементы и предоплату без рабочей оплаты.
- Выдумывать скидки и акции.
