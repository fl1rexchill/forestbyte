# Салон красоты — `beauty/`

Адаптация `sites/niches/beauty/`.
Цель посетителя: выбрать услуги, мастера и желаемое время визита.
Главное действие: «Выбрать услуги» → «Записаться».

## Блоки страницы

1. Первый экран: выразительный заголовок с курсивом, коллаж крупных фото.
2. Услуги по категориям: волосы, ногти, брови, ресницы, макияж. На сайте только категории из `categories`.
3. Мастера со специализациями. Кнопка «Работы мастера» включает фильтр портфолио.
4. Портфолио с фильтром по услуге и мастеру.
5. Цены всех категорий.
6. Отзывы, вопросы, запись, контакты.
7. Нижняя панель визита: число услуг, общая цена и длительность. Панель прячется у формы и учтена в отступе страницы.

## Сценарий записи

Услуги → мастер → желаемое время → контакт.

- Несколько услуг: сайт суммирует цену и длительность (минимум и максимум).
- Несовместимые услуги нельзя выбрать вместе — появляется пояснение.
- Шаг «Мастер» показывает только мастеров, которые выполняют все выбранные услуги. Всегда есть «Любой подходящий мастер».
- Для услуги с `consultFirst: true` сайт предлагает добавить консультацию.
- Расписания нет: сайт запрашивает желаемое время и не показывает свободные окна.
- Сертификаты, абонементы и предоплата выключены: нет рабочего сценария оплаты.
- Тип заявки в CRM: `visit_request`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `hero.accent` | строка | Часть заголовка, которая выделяется курсивом. |
| `hero.collage[]` | id из `assets` | Два дополнительных фото коллажа. |
| `categories[]` | `{ id, name }` | Категории. Удалённая категория исчезает вместе с услугами. |
| `services[]` | `{ id, cat, name, composition[], duration, price, consultFirst, demo }` | Услуги: состав, длительность, цена. |
| `compatibility.exclusive[]` | `[id1, id2, 'пояснение']` | Пары услуг, которые нельзя выбрать в одном визите. |
| `team[]` | `{ id, name, role, services[], photo, demo }` | Мастера. `services` — `id` услуг: по ним проверяется квалификация. |
| `portfolio[]` | `{ id, title, service, master, image, demo }` | Работы. Фильтр — по категории услуги и мастеру. |
| `booking.dayParts[]` | строки | Варианты части дня. |
| `features` | `team`, `portfolio`, `reviews`, `certificates`, `subscriptions`, `prepayment` | Сертификаты, абонементы и предоплата не реализованы: включайте их только вместе с рабочим сценарием оплаты. |

## Пример замены данных

```js
categories: [{ id: 'hair', name: 'Волосы' }, { id: 'nails', name: 'Ногти' }],
services: [{ id: 'haircut', cat: 'hair', name: 'Стрижка', composition: ['мытьё', 'стрижка'], duration: 60, price: { type: 'from', value: 2500 } }],
team: [{ id: 'm-anna', name: 'Анна', role: 'Стилист', services: ['haircut'], photo: 'anna' }]
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js beauty`.
