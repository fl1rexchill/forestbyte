# Салон красоты — `beauty/`

Адаптация `sites/niches/beauty/`.
Цель посетителя: выбрать услуги, мастера и желаемое время визита.
Главное действие: «Собрать визит» → «Записаться».

## Блоки страницы

Стиль шаблона — «палетка»: нюдовый фон и корпус, детали цвета розового золота, винный акцент, бархатный бордовый — полоса записи. У каждой категории свой цвет «пэна» (`categories[].color`) — плоская матовая пудра с зерном. Playfair Display тонким начертанием (курсив — акценты), Montserrat для текста.

1. Первый экран — открытая палетка: нюдовый корпус, в крышке — зеркало в ободке розового золота (фото `hero.image` с розовым отсветом и бликами) с заголовком и кнопкой «Собрать визит», шарнир, в основании — матовые «пэны» категорий в металлических чашках с ценой «от». Пэн ведёт к услугам категории. При загрузке крышка открывается. На экране 1440×900 палетка видна целиком.
2. Услуги и цены — все категории сразу (отдельного блока «Цены» больше нет): состав, длительность, цена, круглая кнопка «+». Добавленная услуга «перелетает» кружком своего цвета в палетку визита внизу экрана.
3. Мастера: фото (если есть — без фото карточка только текстом, без кружков с буквами), категории, должность, услуги, «Работы мастера».
4. Работы — лента с прокруткой вбок и стрелками; фильтр: категории кнопками в одну строку, мастер — выпадающим списком.
5. Отзывы (пример отзыва в демо — мелким серым текстом) и вопросы карточками в две колонки.
6. Запись: визит → мастер → желаемое время → контакт. Слева — шаги. Пустой визит предлагает готовые сочетания (`visitIdeas`) — одной кнопкой в визит кладутся несколько услуг.
7. Палетка визита внизу экрана: по кружку на услугу, число услуг, общая цена и длительность. Прячется у формы записи.
8. Контакты — визитка салона: название, «Салон красоты · город», контакты в строку, кнопки.

## Сценарий записи

Услуги → мастер → желаемое время → контакт.

- Несколько услуг: сайт суммирует цену и длительность (минимум и максимум).
- Несовместимые услуги нельзя выбрать вместе — появляется пояснение.
- Шаг «Мастер» показывает только мастеров, которые выполняют все выбранные услуги. Всегда есть «Любой подходящий мастер».
- Для услуги с `consultFirst: true` сайт предлагает добавить консультацию.
- Расписания нет: сайт запрашивает желаемое время и не показывает свободные окна.
- Желаемый день — кнопки на две недели вперёд (дни, которых нет в `contacts.hours`, недоступны), время суток — сегменты. Системных элементов в форме нет.
- Сертификаты, абонементы и предоплата выключены: нет рабочего сценария оплаты.
- Тип заявки в CRM: `visit_request`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `hero.accent` | строка | Часть заголовка, которая выделяется курсивом. |
| `categories[]` | `{ id, name, color }` | Категории. `color` — цвет «пэна» в палетке. Удалённая категория исчезает вместе с услугами. |
| `services[]` | `{ id, cat, name, composition[], duration, price, consultFirst, demo }` | Услуги: состав, длительность, цена. |
| `compatibility.exclusive[]` | `[id1, id2, 'пояснение']` | Пары услуг, которые нельзя выбрать в одном визите. |
| `visitIdeas[]` | `{ title, services[] }` | Готовые сочетания для пустого визита. Показываются, только если все услуги есть и их можно совместить. |
| `team[]` | `{ id, name, role, services[], photo, demo }` | Мастера. `services` — `id` услуг: по ним проверяется квалификация. |
| `portfolio[]` | `{ id, title, service, master, image, demo }` | Работы. Фильтр — по категории услуги и мастеру. |
| `booking.dayParts[]` | строки | Варианты части дня. |
| `features` | `team`, `portfolio`, `reviews`, `certificates`, `subscriptions`, `prepayment` | Сертификаты, абонементы и предоплата не реализованы: включайте их только вместе с рабочим сценарием оплаты. |

## Мобильная версия (до 760 px)

Та же информация, что на компьютере, но компактнее. Компьютер и планшет не меняются.

- Пэны палетки — одним рядом с прокруткой.
- Все категории услуг на странице; над ними чипы категорий, закреплённые под шапкой.
- Мастера листаются вбок (карусель со счётчиком).
- Демо-плашка — одной строкой.

## Пример замены данных

```js
categories: [{ id: 'hair', name: 'Волосы' }, { id: 'nails', name: 'Ногти' }],
services: [{ id: 'haircut', cat: 'hair', name: 'Стрижка', composition: ['мытьё', 'стрижка'], duration: 60, price: { type: 'from', value: 2500 } }],
team: [{ id: 'm-anna', name: 'Анна', role: 'Стилист', services: ['haircut'], photo: 'anna' }]
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js beauty`.
