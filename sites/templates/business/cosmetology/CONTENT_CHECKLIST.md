# Данные бизнеса для шаблона `cosmetology`

Заполните поля в `config.js`. После замены удалите `demo: true` у записи.

## Обязательно

| Данные | Поле `config.js` |
|---|---|
| [НАЗВАНИЕ] клиники или кабинета | `brand.name`, `brand.logoText` |
| [ОПИСАНИЕ] без медицинских обещаний | `brand.description`, `seo.description` |
| [ГОРОД], [АДРЕС], [ЧАСЫ РАБОТЫ] | `contacts.city`, `contacts.address`, `contacts.hours` |
| [ТЕЛЕФОН], [ПОЧТА] или [TELEGRAM] — хотя бы один | `contacts.*` |
| [УСЛУГИ], [КАТЕГОРИИ], [ЦЕНЫ], [ДЛИТЕЛЬНОСТЬ] | `services`, `categories` |
| [УТВЕРЖДЁННЫЕ ТЕКСТЫ] описания, подготовки и ограничений — или оставить `approved: false` | `services[].description`, `preparation`, `limitations`, `approved` |
| [СПЕЦИАЛИСТЫ]: имя, роль, услуги; фото — с согласия | `team` |
| [ЛИЦЕНЗИЯ НА МЕДИЦИНСКУЮ ДЕЯТЕЛЬНОСТЬ], если услуги медицинские | `licenses`, `legal.medicalLicense` |
| [ПРЕДУПРЕЖДЕНИЕ] для рекламы медицинских услуг — формулировка юриста | `legal.medicalWarning` |
| [ЮРИДИЧЕСКОЕ ЛИЦО], [ИНН], [ОГРН], [ЮРИДИЧЕСКИЙ АДРЕС] | `legal.operator`, `legal.inn`, `legal.ogrn`, `legal.address` |
| [ПОЧТА ДЛЯ ЗАПРОСОВ ПО ДАННЫМ], [АДРЕС САЙТА], [ДАТА ПОЛИТИКИ] | `legal.email`, `legal.site`, `legal.effectiveDate` |
| Подтверждение юриста по текстам документов | `legal.approved: true` |

## Рекомендуется

| Данные | Поле |
|---|---|
| [ДИПЛОМЫ И СЕРТИФИКАТЫ] специалистов — только подтверждённые | `team[].credentials` |
| [ОБОРУДОВАНИЕ]: модель, производитель, номер регистрационного удостоверения | `equipment` |
| [ФОТО ПРОСТРАНСТВА] | `space`, `assets` |
| [РЕЗУЛЬТАТЫ] — фото с письменным согласием пациента | `results` (`consentConfirmed: true`) |
| [ВОПРОСЫ И ОТВЕТЫ] | `faq` |

## Нельзя

- Обещать гарантированный эффект или отсутствие рисков.
- Публиковать сгенерированные или обработанные «результаты».
- Добавлять в форму вопросы о здоровье.
- Указывать квалификацию без документов.
