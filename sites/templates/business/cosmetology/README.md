# Косметология — `cosmetology/`

Адаптация `sites/niches/cosmetology/`.
Цель посетителя: изучить услуги и специалистов, затем запросить консультацию.
Главное действие: «Записаться на консультацию».

## Блоки страницы

Стиль шаблона — «сыворотка»: фарфоровый фон, мягкое свечение (персик, аква, сирень), стекло и капля сыворотки, белые карточки с крупными скруглениями. Главная кнопка — чернильная (`brand.colors.accent`), детали — янтарь сыворотки. Manrope — заголовки тонким начертанием и подписи капителью, Onest — текст и цены.
Оговорки (цена — ориентир, показания уточняет специалист, примеры в демо) — короткими строками рядом с ценами и под шагами, без сносок.

1. Обложка: строка с рубрикой, городом и часами, крупный заголовок — на нём лежит стеклянная капля и преломляет буквы под собой (при загрузке падает и растекается, на компьютере чуть тянется за курсором), подзаголовок (`hero.text`) с кнопкой записи на консультацию, «как это устроено» тремя шагами (`hero.steps`) на матовом стекле: консультация (длительность, цена, «Выбрать время») → план ухода → процедура (ссылка на услуги). Под шагами — предупреждение `legal.medicalWarning`.
2. Специалисты: фото (если есть — без фото карточка только текстом, без кружков с буквами), должность, список услуг, подтверждённая квалификация, запись к специалисту.
3. Услуги и цены — прайсом на белой карточке: категории подписью капителью, название, отточия, цена. Строка раскрывается: описание, длительность, кто ведёт, медицинские тексты (только `approved: true`) и запись. Под прайсом — строка «Цены — ориентир».
4. Кабинет: три-четыре фото одной высоты в общей тёплой обработке, подпись — только если задана; ниже оборудование.
5. Результаты и документы — только подтверждённые, пустые списки скрывают блоки.
6. Вопросы — белыми карточками в две колонки, вопрос и ответ видны сразу; разметка FAQPage.
7. Запрос консультации (сводка запроса слева обновляется по мере выбора).
8. Контакты — белая карточка: фраза-приглашение с длительностью и ценой консультации, кнопка записи, ниже контакты в строку.

## Медицинские сведения

- Описание, подготовка и ограничения услуги выводятся, только если `approved: true`.
- Без утверждённого текста карточка пишет: «Показания, подготовку и ограничения уточняет специалист на консультации».
- Медицинские тексты исходного демо `sites/niches/cosmetology/` не перенесены.
- Форма не собирает анамнез. Над формой и под комментарием написано, что сведения о здоровье указывать не нужно.
- Сайт не ставит диагноз и не назначает процедуру по ответам формы.
- Предупреждение для рекламы медицинских услуг — `legal.medicalWarning`, сведения о лицензии — `legal.medicalLicense`.

## Сценарий запроса

1. «Услуга»: консультация (рекомендуем) или конкретная услуга из списка, специалист или «Помогите выбрать».
2. «Время»: желаемый день — кнопки на две недели (дни, которых нет в `contacts.hours`, недоступны), время суток.
3. «Контакт»: имя, телефон, комментарий, согласие.

- Системных элементов нет: свои радиокнопки, выбор дня, сегменты времени, чекбокс согласия.

- Список специалистов на шаге 2 содержит только тех, кто ведёт выбранную услугу.
- Кнопка «Записаться к специалисту» подставляет специалиста и консультацию. Если он не ведёт консультацию — его первую услугу.
- Тип заявки в CRM: `consult_request`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `categories[]` | `{ id, name }` | Категории каталога. |
| `services[]` | `{ id, cat, name, summary, duration, price, description, preparation, limitations, approved, demo }` | Услуги. `summary` — нейтральный текст без обещаний. Медицинские поля — только утверждённые клиникой. |
| `team[]` | `{ id, name, role, services[], photo, credentials[], demo }` | Специалисты. `services` — `id` услуг. |
| `team[].credentials[]` | `{ title, issuer, year, number }` | Подтверждённые документы об образовании и квалификации. Пустой список — блок квалификации скрыт. |
| `equipment[]` | `{ name, text, image, demo }` | Оборудование: модель, производитель, регистрационное удостоверение. |
| `space[]` | id из `assets` или `{ image, caption, ratio, focus }` | Фото пространства одной высоты. `ratio` — пропорция кадра, `focus` — какая часть фото остаётся в кадре (`'20% 50%'`). |
| `licenses[]` | `{ title, number, date, issuer, url }` | Лицензия клиники. Без `number` запись не выводится. |
| `results[]` | `{ image, caption, consentConfirmed }` | Фото результатов. Выводится только запись с `consentConfirmed: true`. |
| `legal.medicalWarning`, `legal.medicalLicense` | строки | Строки в подвале. Формулировку проверяет юрист. |
| `booking.dayParts[]` | строки | Варианты части дня. Текст после запятой выводится мелко: «Утро, до 12:00». |
| `hero.steps[]` | `{ title, text, service, link }` | Шаги на обложке. `service` — `id` услуги: у шага выводятся её длительность, цена и кнопка записи; `link` — `{ label, target }` для ссылки на блок. |

## Мобильная версия (до 760 px)

Та же информация, что на компьютере, но компактнее. Компьютер и планшет не меняются.

- Шаги на обложке — плотный список: номер слева, текст справа.
- Специалисты и фото кабинета листаются вбок (карусель со счётчиком); у специалиста три услуги и «ещё N».
- Над прайсом — чипы категорий для перехода.
- Сводка запроса появляется, когда что-то выбрано.
- Вопросы — вопрос и ответ видны сразу, как на компьютере.
- Демо-плашка — одной строкой.

## Пример замены данных

```js
services: [{ id: 'consult', cat: 'consult', name: 'Консультация врача-косметолога', summary: 'Осмотр и план ухода.',
  duration: 40, price: { type: 'fixed', value: 2000 },
  description: 'Текст, утверждённый клиникой.', preparation: '…', limitations: '…', approved: true }],
licenses: [{ title: 'Лицензия на медицинскую деятельность', number: 'Л041-…', date: '01.01.2024', issuer: '…' }]
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js cosmetology`.
