# Косметология — `cosmetology/`

Адаптация `sites/niches/cosmetology/`.
Цель посетителя: изучить услуги и специалистов, затем запросить консультацию.
Главное действие: «Записаться на консультацию».

## Блоки страницы

1. Первый экран: светлый фон, фото пространства, кнопка «Записаться на консультацию».
2. Специалисты — сразу после первого экрана: роль, услуги, квалификация из документов.
3. Услуги и цены с фильтром по категории. Карточка услуги в модальном окне.
4. Оборудование, пространство.
5. Результаты — только подтверждённые фото с согласием пациента. Пустой список скрывает блок.
6. Документы (лицензии) — только подтверждённые. Пустой список скрывает блок и пункт меню.
7. Вопросы, запрос консультации, контакты.

## Медицинские сведения

- Описание, подготовка и ограничения услуги выводятся, только если `approved: true`.
- Без утверждённого текста карточка пишет: «Показания, подготовку и ограничения уточняет специалист на консультации».
- Медицинские тексты исходного демо `sites/niches/cosmetology/` не перенесены.
- Форма не собирает анамнез. Над формой и под комментарием написано, что сведения о здоровье указывать не нужно.
- Сайт не ставит диагноз и не назначает процедуру по ответам формы.
- Предупреждение для рекламы медицинских услуг — `legal.medicalWarning`, сведения о лицензии — `legal.medicalLicense`.

## Сценарий запроса

Услуга или консультация → специалист или «Помогите выбрать» → желаемое время → контакт.

- Список специалистов на шаге 2 содержит только тех, кто ведёт выбранную услугу.
- Кнопка «Записаться к специалисту» подставляет специалиста и консультацию. Если он не ведёт консультацию — его первую услугу.
- Тип заявки в CRM: `consult_request`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `categories[]` | `{ id, name }` | Категории каталога. |
| `services[]` | `{ id, cat, name, summary, duration, price, description, preparation, limitations, approved, demo }` | Услуги. `summary` — нейтральный текст без обещаний. Медицинские поля — только утверждённые клиникой. |
| `team[]` | `{ id, name, role, services[], photo, credentials[], demo }` | Специалисты. `services` — `id` услуг. |
| `team[].credentials[]` | `{ title, issuer, year, number }` | Подтверждённые документы об образовании и квалификации. Пустой список — блок квалификации скрыт. |
| `equipment[]` | `{ name, text, image, demo }` | Оборудование: модель, производитель, регистрационное удостоверение. |
| `space[]` | id из `assets` | Фото пространства. |
| `licenses[]` | `{ title, number, date, issuer, url }` | Лицензия клиники. Без `number` запись не выводится. |
| `results[]` | `{ image, caption, consentConfirmed }` | Фото результатов. Выводится только запись с `consentConfirmed: true`. |
| `legal.medicalWarning`, `legal.medicalLicense` | строки | Строки в подвале. Формулировку проверяет юрист. |
| `booking.dayParts[]` | строки | Варианты части дня. |

## Пример замены данных

```js
services: [{ id: 'consult', cat: 'consult', name: 'Консультация врача-косметолога', summary: 'Осмотр и план ухода.',
  duration: 40, price: { type: 'fixed', value: 2000 },
  description: 'Текст, утверждённый клиникой.', preparation: '…', limitations: '…', approved: true }],
licenses: [{ title: 'Лицензия на медицинскую деятельность', number: 'Л041-…', date: '01.01.2024', issuer: '…' }]
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js cosmetology`.
