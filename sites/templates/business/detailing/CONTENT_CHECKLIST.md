# Данные бизнеса для шаблона `detailing`

Заполните поля в `config.js`. После замены удалите `demo: true` у записи.

## Обязательно

| Данные | Поле `config.js` |
|---|---|
| [НАЗВАНИЕ] студии | `brand.name`, `brand.logoText` |
| [ОПИСАНИЕ] | `brand.description`, `seo.description` |
| [ГОРОД], [АДРЕС], [ЧАСЫ РАБОТЫ] | `contacts.city`, `contacts.address`, `contacts.hours` |
| [ТЕЛЕФОН], [ПОЧТА] или [TELEGRAM] — хотя бы один | `contacts.*` |
| [КЛАССЫ АВТОМОБИЛЕЙ] и коэффициенты | `carClasses` |
| [УСЛУГИ], [ВАРИАНТЫ], [ЦЕНЫ], [ДЛИТЕЛЬНОСТЬ] | `services[].zones` |
| [ОГРАНИЧЕНИЯ] услуг | `services[].limits` |
| [ПАКЕТЫ]: состав, ограничения, цена — или пустой список | `packages` |
| [ДОПУСЛУГИ] и цены | `extras` |
| [ЮРИДИЧЕСКОЕ ЛИЦО], [ИНН], [ОГРН], [ЮРИДИЧЕСКИЙ АДРЕС] | `legal.operator`, `legal.inn`, `legal.ogrn`, `legal.address` |
| [ПОЧТА ДЛЯ ЗАПРОСОВ ПО ДАННЫМ], [АДРЕС САЙТА], [ДАТА ПОЛИТИКИ] | `legal.email`, `legal.site`, `legal.effectiveDate` |
| Подтверждение юриста по текстам документов | `legal.approved: true` |

## Рекомендуется

| Данные | Поле |
|---|---|
| [РАБОТЫ] студии с фото и услугой | `portfolio` |
| [ПАРЫ ДО/ПОСЛЕ] одной работы с разрешением владельца автомобиля | `beforeAfter` (`sameCar: true`, без `illustration`) |
| [МАТЕРИАЛЫ]: марки плёнки, керамики, паст | `materials` |
| [ГАРАНТИИ] из договора или документов производителя | `warranty` |
| [ПАМЯТКА ПО УХОДУ] для каждого покрытия | `care` |
| [КОМАНДА] с согласия сотрудников | `team` |
| [ОТЗЫВЫ] с источником | `reviews` |

## Фото

- Замените стоковые фото и SVG-иллюстрации «до/после».
- Не выдавайте два разных автомобиля за результат одной работы.
- Скрывайте госномера на фото.
- Для каждого файла заполните `assets`.

## Нельзя

- Обещать срок службы покрытия и гарантию без документов.
- Выдумывать скидки и число выполненных работ.
