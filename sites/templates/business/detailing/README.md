# Детейлинг-студия — `detailing/`

Цель посетителя: выбрать уход или защиту автомобиля и запросить расчёт.
Главное действие: «Рассчитать стоимость».

## Блоки страницы

Стиль шаблона — «инспекционный свет»: графит, белый и холодный свет лампы. Цветного акцента нет — цвет дают фото.
Сквозной приём — световые полосы бокса: тонкие светящиеся линии над этапами процесса, над колонкой пакета при наведении,
над плашкой ориентира и финальной панелью. Шрифт один — Manrope: тонкие крупные заголовки, мелкие подписи капителью с разрядкой.

1. Первый экран: капот тёмного автомобиля в боксе, нарисованный на canvas (лак, рёбра, стыки с крыльями, лобовое стекло, отражения ламп потолка), и инспекционная лампа. Свет идёт за курсором и проявляет лак и голограммы — кольца мелких царапин вокруг блика; без курсора лампа сама медленно ходит по капоту, на телефоне — ещё и за пальцем. Переключатель «До полировки / После» — проход полировальника стирает царапины. Без анимаций лампа стоит на месте. Внизу заголовок, текст и кнопка «Рассчитать стоимость».
2. Услуги — перечень строками: номер, название, цена «от». Строка раскрывается: варианты с длительностью и ценой, ограничения, кнопка расчёта. На компьютере справа закреплено фото услуги, оно меняется при наведении на строку; на телефоне фото внутри раскрытой строки.
3. Пакеты — лист сравнения: колонки без карточек, строки (цена, состав, условия, кнопка) выровнены между колонками.
4. Работы — ровная сетка 4:3 с фильтром по услуге. Фото чёрно-белые и становятся цветными под курсором, на телефоне — когда проходят середину экрана.
5. До/после — только пара реальных фото одного автомобиля. Пустой `beforeAfter` — блока нет.
6. Как работаем: линия над этапами загорается по очереди; ниже паспорт работы в три колонки — материалы, команда, уход после студии (и гарантии, если они есть).
7. Расчёт на одном экране и контакт.
8. Вопросы — нумерованные строки на всю ширину; отзывы; финальная панель «Приезжайте на осмотр» с контактами одной строкой.

## Сценарий расчёта

Шаг 1 «Работа» на одном экране: класс автомобиля, услуга (или готовый пакет), вариант, допуслуги. Цены вариантов и допуслуг сразу показаны для выбранного класса.
Шаг 2 «Контакт».

- Необязательные поля: марка, модель, комментарий, до трёх фото автомобиля.
- Плашка «Ориентир» показывает строки расчёта, итог и время в студии; до выбора в ней видно, чего не хватает. При смене суммы по плашке проходит блик.
- Своих элементов вместо системных: класс — сегменты, услуга и допуслуги — таблетки, вариант — карточки, фото — своя кнопка и перетаскивание.
- Под итогом всегда написано, что итоговую стоимость уточняют после осмотра.
- Тип заявки в CRM: `detailing_quote`.

## Поля `config.js` этой ниши

| Поле | Тип | Назначение |
|---|---|---|
| `carClasses[]` | `{ id, name, example, coef }` | Классы автомобиля. `coef` умножает цену зоны, пакета и допуслуги с `coef: true`. |
| `services[]` | `{ id, name, short, image, zones[], limits[] }` | Услуги. `zones` — варианты услуги. |
| `services[].zones[]` | `{ id, name, price, duration, demo }` | Вариант: цена и длительность в минутах или `{ min, max }`. |
| `packages[]` | `{ id, name, composition[], includes[], limits[], price, duration, demo }` | Готовые наборы. `includes` — `id` услуг. |
| `extras[]` | `{ id, name, price, coef, demo }` | Допуслуги. `coef: false` — цена не зависит от класса. |
| `portfolio[]` | `{ id, title, service, image, demo }` | Работы. `service` — `id` услуги для фильтра. |
| `beforeAfter[]` | `{ id, title, service, before, after, sameCar, demo }` | Пара реальных фото «до/после». Показывается только при `sameCar: true` и наличии обоих файлов. В демо список пуст — блока нет. |
| `process[]` | `{ title, text }` | Этапы работы. |
| `materials[]` | `{ name, text, demo }` | Материалы. Укажите реальные марки. |
| `care[]` | строки | Памятка по уходу. |
| `warranty[]` | строки | Гарантии из документов студии. Пустой список скрывает блок. |
| `pricing.note` | строка | Пояснение под итогом расчёта. |
| `hero.image` | id из `assets` | На странице не выводится (капот на первом экране рисуется), используется для `og:image`. |
| `brand.colors.accent` | цвет | Главная кнопка и выбранные варианты. По умолчанию белый `#ecebe7`; на тёмном фоне нужен светлый цвет. |
| `features` | `portfolio`, `beforeAfter`, `team`, `reviews`, `packages` | `false` скрывает блок. |

## Как считается ориентир

Ориентир = цена зоны или пакета × `coef` класса + допуслуги (× `coef` класса, если у допуслуги `coef: true`).
Цена с коэффициентом округляется до 10 ₽. Цена без коэффициента выводится как есть.

## Мобильная версия (до 760 px)

Та же информация, что на компьютере, но компактнее. Компьютер и планшет не меняются.

- Капот на первом экране ниже — заголовок и кнопка расчёта видны сразу.
- Все строки услуг свёрнуты; пакеты листаются вбок (карусель со счётчиком).
- Работы — сетка в две колонки, фильтр одной строкой с прокруткой.
- Паспорт работы — три раскрывающиеся строки: материалы, команда, после студии (с числом пунктов).
- Пока видна форма расчёта, а плашка «Ориентир» за экраном, внизу — сумма ориентира и ссылка к плашке.
- Демо-плашка — одной строкой.

## Пример замены данных

```js
carClasses: [{ id: 'small', name: 'Малый', example: 'Kia Rio', coef: 1 }, { id: 'suv', name: 'Внедорожники', example: 'Land Cruiser', coef: 1.5 }],
services: [{ id: 'polish', name: 'Полировка кузова', short: '…', image: 'polish', zones: [
  { id: 'polish-light', name: 'Лёгкая', price: { type: 'from', value: 15000 }, duration: 480 }
], limits: ['Глубокие царапины до грунта не убираем'] }]
```

Перед публикацией заполните `CONTENT_CHECKLIST.md` и выполните `node sites/templates/business/_shared/config-check.js detailing`.
