# Event-агентство — `event/`

Цель посетителя: выбрать формат события и передать бриф.
Главное действие: «Обсудить мероприятие».

## Блоки страницы

1. Первый экран: заголовок, кнопка «Обсудить мероприятие», фото. На телефоне текст идёт первым.
2. Форматы: корпоративы, конференции, презентации, частные события. Кнопки «Проекты» и «Обсудить».
3. Проекты с фильтром по формату. Размер плиток подбирается по числу проектов, сетка без пустых мест. Карточка проекта в модальном окне: цифры кейса, задача, состав работ, галерея.
4. Прайс как меню: описание, результат «На руках», цена крупно и кнопка «В смету». Кейтеринг — необязательная услуга.
5. Тайминг — свой элемент шаблона. Пример дня события по минутам и этапы подготовки до него.
6. Команда — бейджи персонала: роль, канал рации, время на площадке и полоска смены на шкале дня.
   Отзывы — билеты: цитата и корешок с данными проекта, кнопка «Смотреть проект» открывает его карточку.
   Вопросы — «Памятка заказчику»: оглавление слева остаётся на экране и подсвечивает текущий вопрос, все ответы открыты. На странице есть разметка FAQPage.
7. Калькулятор: параметры одной фразой, услуги-переключатели и смета-документ, которая пересчитывается сразу. Второй шаг — контакт.
8. Контакты и юридические страницы.

## Дизайн и анимации

- Unbounded капсом — только в первом экране. Заголовки разделов — Unbounded обычным регистром, время и подписи — JetBrains Mono.
- Lenis и anime.js на странице не подключены: прокрутка нативная, анимации — CSS и Web Animations API.
- Тайминг: линия заполняется по прокрутке, пройденные пункты подсвечиваются. Ключевая точка (`accent: true`) крупнее и в цвете акцента.
- Фильтр проектов: оставшиеся карточки переезжают на новые места (FLIP), новые проявляются.
- Смета: новые строки «впечатываются» в лист, итог перещёлкивается от старой суммы к новой.
- Прайс и калькулятор — одно состояние: «В смету» в прайсе отмечает услугу в калькуляторе и наоборот. Когда в смете что-то есть, а лист сметы за экраном, внизу появляется плашка «Смета · сумма → Открыть». На телефоне она заменяет нижнюю кнопку.
- Бейджи команды слегка качаются на ленте при наведении (только мышь и без `prefers-reduced-motion`). На телефоне бейджи листаются вбок.
- При `prefers-reduced-motion` переходы отключены, подсветка тайминга остаётся без анимации.
- Демо-метки стоят одной строкой на блок (услуги, команда), а не у каждой записи. Подсказки разработчику о незаполненных контактах и реквизитах выводятся в консоль браузера.

## Сценарий брифа

Два шага: «Событие» и «Контакт».

1. Фраза «Планируем [формат] на [N] гостей. Дата — [дата], город — [город]. Бюджет — [бюджет].» Каждое подчёркнутое слово — поле с подписью для скринридера, ошибка выводится под словом. Ниже — услуги-переключатели.
2. Контакт: имя, телефон, почта, компания, площадка, комментарий, файл брифа (PDF или изображение до 10 МБ), согласие.

- «Дата пока не известна» отключает поле даты, во фразе остаётся «обсудим».
- «Бюджет обсуждается» — вариант «обсудим» в списке бюджета.
- Кнопки «Обсудить …» в форматах и проектах выбирают формат во фразе.
- Тип заявки в CRM: `event_brief`. Сообщение после отправки: «Бриф принят для обсуждения».
- Сайт не показывает занятость дат агентства.

## Поля `config.js` этой ниши

Общие группы описаны в `../README.md`.

| Поле | Тип | Назначение |
|---|---|---|
| `formats[]` | `{ id, name, phrase, short, image }` | Форматы событий. `id` используют проекты, бриф и тарифы. `phrase` — формат в винительном падеже для фразы калькулятора («корпоратив», «конференцию»). |
| `services[]` | `{ id, name, text, deliverable, price, optional, demo }` | Услуги агентства. `deliverable` — что клиент получает на руки. `optional: true` — метка «по запросу». |
| `timing` | `{ title, items[], demo }` | Пример тайминга дня события. `items[]`: `{ time: 'ЧЧ:ММ', title, text, accent }`; `accent: true` — ключевая точка. Это иллюстрация, а не обещание сроков. |
| `stages[]` | `{ title, text }` | Этапы подготовки до дня события. Без обещаний сроков. |
| `portfolio[]` | `{ id, title, format, cover, gallery[], guests, venue, prep, task, works[], demo }` | Проекты. `format` — `id` формата. `guests`, `venue`, `prep` — цифры кейса; пустое поле не выводится. |
| `team[]` | `{ id, name, role, area, channel, onSite, photo, demo }` | Бейджи команды. Пустое `name` — выводится роль. `channel` — канал рации. `onSite: { from, to }` — время на площадке в день события, `'ЧЧ:ММ'`; время до 06:00 считается ночью после события. Без фото на бейдже — инициалы. |
| `reviews[]` | `{ text, author, project, date, source, url, demo }` | Отзывы-билеты. `project` — `id` проекта: на корешке появятся название, площадка и гости, кнопка откроет проект. `date` — строка, например `'декабрь 2025'`. `source` и `url` — где опубликован отзыв. |
| `faq[]` | `{ q, a }` | Вопросы памятки. Номера и оглавление строятся автоматически. |
| `pricing.mode` | `'estimate'` или `'request'` | `estimate` — показывать смету; `request` — только «Запросить смету». |
| `pricing.formats` | `{ <id формата>: { price, perGuest } }` | Организация: база (`price`) и сумма за каждого гостя. |
| `pricing.budgets[]` | строки | Варианты бюджета в брифе. «Бюджет обсуждается» добавляется всегда. |
| `pricing.maxGuests` | число | Верхняя граница числа гостей. |
| `booking.successTitle`, `successText` | строки | Текст после отправки брифа в рабочем режиме. |
| `features` | `timing`, `team`, `reviews`, `estimate` | `false` скрывает блок. |

## Как считается смета

Смета = организация по формату (`price`) + `perGuest` × число гостей + цены выбранных услуг.
Если есть цена «от», итог — «от …». Если есть услуга «по запросу», к итогу добавляется «+ N позиций по запросу».
Если `pricing.mode: 'request'` или `features.estimate: false`, сайт предлагает запросить смету.

## Пример замены данных

```js
brand: { name: 'Название агентства', logoText: 'Название', colors: { accent: '#e8412c' } },
contacts: { phone: '+7 (495) 123-45-67', email: 'hello@agency.ru', telegram: 'agency', city: 'Москва', address: 'ул. Примерная, 1' },
services: [
  { id: 'concept', name: 'Концепция и сценарий', text: 'Идея и драматургия вечера.', price: { type: 'from', value: 60000 } }
]
```
