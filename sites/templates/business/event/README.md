# Event-агентство — `event/`

Цель посетителя: выбрать формат события и передать бриф.
Главное действие: «Обсудить мероприятие».

## Блоки страницы

1. Первый экран: формат работы, кнопка «Обсудить мероприятие», метки форматов.
2. Форматы: корпоративы, конференции, презентации, частные события. Кнопки «Проекты» и «Обсудить».
3. Проекты с фильтром по формату. Плитки разного размера. Карточка проекта в модальном окне: задача, состав работ, формат, галерея.
4. Услуги: концепция, площадка, программа, техника, декор, координация. Кейтеринг — необязательная услуга.
5. Этапы подготовки.
6. Команда (роли), отзывы, вопросы.
7. Бриф из пяти шагов и предварительная смета.
8. Контакты и юридические страницы.

## Сценарий брифа

Формат → дата и город → гости и бюджет → нужные услуги → контакт.

- «Дата не выбрана» отключает поле даты.
- «Бюджет обсуждается» — отдельный вариант.
- Необязательные поля: площадка, компания, файл брифа (PDF или изображение до 10 МБ).
- Тип заявки в CRM: `event_brief`. Сообщение после отправки: «Бриф принят для обсуждения».
- Сайт не показывает занятость дат агентства.

## Поля `config.js` этой ниши

Общие группы описаны в `../README.md`.

| Поле | Тип | Назначение |
|---|---|---|
| `formats[]` | `{ id, name, short, image }` | Форматы событий. `id` используют проекты, бриф и тарифы. |
| `services[]` | `{ id, name, text, price, optional, demo }` | Услуги агентства. `optional: true` — метка «по запросу». |
| `stages[]` | `{ title, text }` | Этапы подготовки. Без обещаний сроков. |
| `portfolio[]` | `{ id, title, format, size, cover, gallery[], task, works[], demo }` | Проекты. `size`: `l`, `m`, `s` — размер плитки. `format` — `id` формата. |
| `team[]` | `{ id, name, role, area, photo, demo }` | Роли команды. Пустое `name` — выводится роль. |
| `pricing.mode` | `'estimate'` или `'request'` | `estimate` — показывать смету; `request` — только «Запросить смету». |
| `pricing.formats` | `{ <id формата>: { price, perGuest } }` | Организация: база (`price`) и сумма за каждого гостя. |
| `pricing.budgets[]` | строки | Варианты бюджета в брифе. «Бюджет обсуждается» добавляется всегда. |
| `pricing.maxGuests` | число | Верхняя граница числа гостей. |
| `booking.successTitle`, `successText` | строки | Текст после отправки брифа в рабочем режиме. |
| `features` | `team`, `reviews`, `estimate` | `false` скрывает блок. |

## Как считается смета

Смета = организация по формату (`price`) + `perGuest` × число гостей + цены выбранных услуг.
Если есть цена «от», итог — «от …». Если есть услуга «по запросу», к итогу добавляется «+ N позиций по запросу».
Если `pricing.mode: 'request'` или `features.estimate: false`, сайт предлагает запросить смету.

```js
  { id: 'concept', name: 'Концепция и сценарий', text: 'Идея и драматургия вечера.', price: { type: 'from', value: 60000 } }

```
