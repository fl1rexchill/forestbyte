Шаблоны сайтов для бизнеса

Пять самостоятельных шаблонов на общем ядре. Данные бизнеса — в config.js каждой папки. Запуск сервера из корня репозитория: node sites/templates/business/server/server.mjs.

Демонстрационные шаблоны. Данные приведены для примера.

  • event

    Event-агентство

    Форматы, проекты с фильтром, бриф из пяти шагов и предварительная смета.

  • detailing

    Детейлинг-студия

    Расчёт по классу автомобиля, пакеты, работы, сравнение до и после.

  • auto

    Автосервис

    Выбор автомобиля, каталог с поиском, работа и запчасти в расчёте отдельно.

  • cosmetology

    Косметология

    Специалисты, каталог услуг, запрос консультации без медицинских данных.

  • beauty

    Салон красоты

    Визит из нескольких услуг, мастер по квалификации, желаемое время.

CRM-панель заявок (нужен ADMIN_TOKEN из server/.env)
