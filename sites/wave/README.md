# WAVE — сайт мебели для ванной (waverus.ru)

Новый сайт бренда WAVE вместо страницы на WordPress/Elementor. Основа — шаблон «Этюд»
(`sites/niches/cosmetology`): журнальная антиква с курсивом, спокойный ритм и мягкое появление блоков.
Палитра переведена в светлую: тёплый фарфор и глубокий бирюзовый из фирменного градиента WAVE.
Резких элементов нет: скругления, тонкие линии, медленные переходы.

Готовый сайт — папка `public/`. Сборки на сервере не нужно: достаточно залить содержимое `public/`
в корень хостинга с PHP.

## Структура

```
_src/
  data.mjs            все тексты: товары, преимущества, FAQ, контакты, оператор ПД
  legal.mjs           политика ПД, согласие, политика cookie
  build.mjs           генератор страниц → public/
  illustrations.mjs   SVG-иллюстрации комплектов (пока нет фото)
  photos/             сюда класть фото моделей (black-groove.webp и т. д.)
  fetch-photos.sh     скачать фото со старого сайта
  images.html, render-images.mjs   OG-картинка, логотип и PNG-иконки (через Chromium)
public/               готовый сайт
  index.html, mebel/…, kontakty/, privacy/, soglasie/, cookies/, 404.html
  api/lead.php        приём заявок → письмо дилеру
  assets/             css, js, шрифты (локально), Lenis, картинки
  sitemap.xml, robots.txt, .htaccess, favicon, site.webmanifest
```

## Страницы

| Адрес | Что там |
|---|---|
| `/` | первый экран, коллекция, материал PVC, о бренде, как купить, контакты и форма, FAQ |
| `/mebel/` | вся коллекция |
| `/mebel/black-matte/`, `/black-groove/`, `/grey-blue/`, `/white-cabinet/` | карточки комплектов: особенности, характеристики, ссылка на товар у дилера, форма «Узнать цену» |
| `/kontakty/` | розница и опт в Омске, форма |
| `/privacy/`, `/soglasie/`, `/cookies/` | документы по 152-ФЗ (закрыты от индексации) |

## Как править

1. Тексты и товары — `_src/data.mjs`, документы — `_src/legal.mjs`.
2. `node _src/build.mjs` — пересобирает все страницы, `sitemap.xml` и иконки товаров.
3. Залить `public/` на хостинг.

Node.js 18+, зависимостей нет. Скрипт `render-images.mjs` нужен только для перерисовки OG-картинки
и иконок (`npm i -D playwright-core`, браузер Chromium).

### Фото товаров

Со старого сайта фото скачать не удалось (закрыт доступ из среды разработки), поэтому сейчас
показываются аккуратные SVG-иллюстрации комплектов с подписью «Иллюстрация».
Чтобы поставить настоящие фото:

```sh
sh _src/fetch-photos.sh      # пока старый сайт ещё работает
node _src/build.mjs
```

или положите файлы вручную в `_src/photos/` с именами `black-matte`, `black-groove`, `grey-blue`,
`white-cabinet` (`.webp`/`.jpg`/`.png`). Лучше webp шириной до 1400 px, кадр 4:5. Сборка сама
возьмёт фото вместо иллюстрации, уберёт подпись и добавит фото в sitemap.

### PDF-каталог

Кнопки «Каталог PDF» ведут на файл, который сейчас лежит в WordPress
(`/wp-content/uploads/2026/04/Каталог-мебель-WAVE.pdf`). Перед отключением WordPress скачайте его,
положите в `public/files/katalog-wave.pdf` и поменяйте `catalogPdf` в `data.mjs`.

## SEO

- уникальные `title` и `description` (до 160 символов) на каждой странице, `canonical`, Open Graph с картинкой 1200×630;
- schema.org: `Organization` (бренд), `FurnitureStore` ×2 (магазин и склад с адресами и телефонами), `Product` на карточках, `FAQPage`, `BreadcrumbList`, `ItemList`;
- один `h1` на странице, семантика `nav/main/article/address/details`, хлебные крошки;
- `sitemap.xml`, `robots.txt` с `Clean-param` для Яндекса (utm, yclid);
- ЧПУ со слэшем на конце, 301 с www/http и с `index.html`, 410 для служебных адресов WordPress (`.htaccess`);
- скорость: без jQuery и сторонних CDN, шрифты woff2 локально с `preload`, картинки с размерами и `loading="lazy"`, CSS/JS с версией в адресе и долгим кэшем;
- доступность: skip-link, видимый фокус, подписи у полей, ошибки текстом, `prefers-reduced-motion`.

После запуска: добавьте сайт в Яндекс Вебмастер и Google Search Console, отправьте `sitemap.xml`,
впишите коды подтверждения в `site.yandexVerification` / `site.googleVerification` и пересоберите.

## 152-ФЗ

- Оператор ПД — тот же, что у alvisplast.ru: **Красноярский Владимир Анатольевич**, `alvisplast@mail.ru`
  (`operator` в `data.mjs`). Текст политики взят с alvisplast.ru и дополнен: цели для формы заявок и
  аналитики, передача дилеру, отказ от трансграничной передачи, локализация баз в РФ.
- Согласие на обработку ПД — **отдельный документ** (`/soglasie/`), как требуется с 01.09.2025.
  Чекбокс в форме не отмечен заранее, без него заявка не уходит (проверка и в браузере, и на сервере).
- Cookie-баннер: «Принять все» / «Только необходимые». **Яндекс Метрика загружается только после
  согласия.** Выбор можно изменить ссылкой «Настройки cookie» в подвале.
- Никаких Google Fonts, Google Maps и сторонних скриптов до согласия: данные посетителей
  не уходят за рубеж. Карты открываются ссылкой на Яндекс Карты.
- `api/lead.php` не хранит заявки: только отправляет письмо дилеру. Для ограничения частоты
  хранится хэш IP и время, без персональных данных.

**Что проверить до запуска (юридически):**
1. Оператор должен быть в реестре операторов ПД Роскомнадзора (pd.rkn.gov.ru), и в уведомлении
   должен быть указан сайт waverus.ru.
2. Если оператор — ИП, стоит добавить ОГРНИП/ИНН и почтовый адрес в `operator` и в тексты.
3. С дилером («Практик») нужно поручение на обработку ПД или договор с условием о конфиденциальности:
   заявки уходят на его почту.
4. Хостинг и почтовые ящики должны быть в России (у `mail.ru` — да).
5. Шаблоны — не юридическая консультация, покажите тексты юристу.

## Метрика и цели

Номер счётчика — `site.yandexMetrikaId` в `data.mjs`. При успешной отправке формы срабатывает цель `lead`
(создайте в Метрике JS-цель с идентификатором `lead`).

## Форма заявок

`public/api/lead.php`: получатель `LEAD_TO` (сейчас `511-238@mail.ru`, розница), отправитель
`LEAD_FROM`. Защита: скрытое поле-ловушка, минимальное время заполнения, проверка Origin,
не больше 5 заявок за 10 минут с одного IP. Без PHP форма честно покажет ошибку и телефон.
Чтобы письма не попадали в спам, настройте на хостинге SPF/DKIM для `waverus.ru` или SMTP.

## nginx (если не Apache)

```nginx
server {
  server_name waverus.ru;
  root /var/www/waverus/public;
  index index.html;
  error_page 404 /404.html;
  location / { try_files $uri $uri/ =404; }
  location ~ ^/(wp-admin|wp-login\.php|wp-json|xmlrpc\.php|feed) { return 410; }
  location = /api/lead.php { include fastcgi_params; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; fastcgi_pass unix:/run/php/php-fpm.sock; }
  location ~* \.(css|js|woff2|svg|png|jpg|webp)$ { expires 1y; add_header Cache-Control "public, immutable"; }
}
```

## Что осталось от старого сайта и что изменено

- Тексты о бренде, описания комплектов, преимущества, адреса и телефоны — со старой страницы,
  переписаны без канцелярита и восклицаний.
- Убраны неподтверждённые цифры («150+ заказов», «4.9 из 5»): без источника они выглядят как выдумка.
- Убран блок «Разработка и сопровождение» (реклама веб-студии, к бренду не относится).
- У комплекта White на старом сайте кнопка вела на карточку Grey-Blue (`product_id=5632`); сейчас
  она ведёт в поиск WAVE у дилера. Нужна правильная ссылка — поправьте `dealerUrl` в `data.mjs`.
- Размеры и цены на сайте не указаны: их не было на старой странице, а выдумывать нельзя. Если
  дадите таблицу размеров, её легко добавить в `specs` каждого товара.
