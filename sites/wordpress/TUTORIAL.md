# 📙 WordPress: установка и подключение — по шагам (для новичка)

Здесь всё максимально просто, по пунктам. Вы установите **плагин Forestbyte**
(виджеты + форма-заявка + CRM) и **тему Forestbyte Starter**, а потом подключите CRM.

> Ничего программировать не нужно. Нужно: зайти в админку WordPress и покликать.

---

## Часть 1. Что вам нужно
1. Работающий сайт на WordPress (свой домен или локальный).
2. Доступ в админку: `https://ваш-сайт.ru/wp-admin`.
3. Права администратора.

---

## Часть 2. Установка плагина Forestbyte

У вас есть папка `sites/wordpress/plugin/forestbyte`. Её нужно превратить в ZIP и загрузить.

### Способ А — через админку (проще всего)
1. Заархивируйте папку `forestbyte` в **ZIP** (внутри архива должна лежать папка `forestbyte`
   с файлом `forestbyte.php`). Быстрый способ — запустите `build-zips` (см. в конце) или
   правой кнопкой по папке → «Отправить» → «Сжатая ZIP-папка».
2. В админке слева: **Плагины → Добавить новый**.
3. Вверху нажмите **«Загрузить плагин»**.
4. Выберите ZIP-файл `forestbyte.zip` → **«Установить»**.
5. Нажмите **«Активировать»**.

### Способ Б — через файлы (FTP/хостинг-панель)
1. Скопируйте папку `forestbyte` целиком в `/wp-content/plugins/` на сервере.
2. В админке: **Плагины** → найдите **Forestbyte** → **«Активировать»**.

✅ После активации слева в меню появится пункт **«Forestbyte»**.

---

## Часть 3. Настройка плагина
1. Откройте **Forestbyte** в левом меню админки.
2. Раздел **«Внешний вид»**:
   - **Цвет акцента** — выберите цвет кнопок (по умолчанию бирюзовый, без фиолетового).
   - **Тема** — Авто / Светлая / Тёмная.
3. Раздел **«CRM»** — пока оставьте «Не подключать» (подключим в Части 6).
4. **E-mail для заявок** — впишите почту, куда дублировать заявки.
5. Нажмите **«Сохранить настройки»**.

---

## Часть 4. Установка темы Forestbyte Starter (необязательно)

Тема даёт готовый каркас и демо-главную. Можно пропустить, если у вас уже своя тема —
виджеты работают в любой теме через шорткоды.

1. Заархивируйте папку `sites/wordpress/theme/forestbyte-starter` в **ZIP**.
2. В админке: **Внешний вид → Темы → Добавить новую → Загрузить тему**.
3. Выберите ZIP → **«Установить»** → **«Активировать»**.

*(Или скопируйте папку `forestbyte-starter` в `/wp-content/themes/` и активируйте.)*

## Часть 5. Как вставить виджет на страницу

Пример — добавим блок «Отзывы»:
1. **Страницы → Добавить новую** (или откройте существующую).
2. Добавьте блок **«Шорткод»** (жмите «+» → найдите «Shortcode»).
   - В классическом редакторе просто впишите шорткод в текст.
3. Вставьте, например:
   ```
   [fb_testimonials autoplay="6000" src="/wp-content/uploads/reviews.json"]
   ```
4. Нажмите **«Опубликовать»** и откройте страницу — виджет на месте.

📋 **Все шорткоды** перечислены на странице настроек плагина (внизу, таблица «Шорткоды виджетов»).

Частые примеры:
```
[fb_stories src="/wp-content/uploads/stories.json"]
[fb_video_circles src="/wp-content/uploads/circles.json"]
[fb_faq single="1" src="/wp-content/uploads/faq.json"]
[fb_counter to="1500" suffix="+"]
[fb_cookie_consent policy="/privacy" categories="1"]
```

### Где взять файлы данных (JSON)
Виджетам сториз/лента/FAQ/отзывы нужны данные. Проще всего:
1. Создайте JSON-файл (формат — в README каждого виджета, папка `sites/components/<виджет>`).
2. Загрузите его: **Медиафайлы → Добавить новый** (перетащите .json; если WP не пускает —
   загрузите по FTP в `/wp-content/uploads/`).
3. Скопируйте адрес файла и вставьте в атрибут `src="..."`.

## Часть 6. Форма-заявка + подключение CRM (самое полезное)

### 6.1. Поставьте форму на страницу
Вставьте шорткод на страницу «Контакты» (или в футер):
```
[fb_lead_form title="Оставить заявку" button="Отправить"]
```
Уже сейчас заявки будут приходить на почту из настроек. Теперь подключим CRM.

### 6.2. Подключите CRM
1. Получите ключ по инструкции своей CRM (там всё по шагам):
   - **Bitrix24:** `sites/integrations/crm/bitrix24/TUTORIAL.md` (2 минуты, одна ссылка).
   - **amoCRM:** `sites/integrations/crm/amocrm/TUTORIAL.md` (нужны поддомен + токен).
2. В админке: **Forestbyte → Настройки → CRM**:
   - Выберите **Bitrix24** или **amoCRM**.
   - Вставьте ключ/ссылку (или поддомен+токен для amoCRM).
   - **Сохранить**.
3. Отправьте тестовую заявку через форму на сайте.
4. Проверьте CRM: **Bitrix24 → CRM → Лиды** или **amoCRM → Сделки** — заявка на месте.

✅ Готово. Теперь заявки с сайта автоматически падают в CRM (и дублируются на e-mail —
даже если CRM временно недоступна, клиент не потеряется).

## Частые проблемы

| Симптом | Решение |
|---------|---------|
| Вместо виджета видно текст `[fb_...]` | Плагин Forestbyte не активирован. Активируйте его. |
| Виджет пустой | Проверьте `src` — файл JSON доступен по этому адресу? Откройте адрес в браузере. |
| Форма шлёт, но в CRM пусто | Проверьте ключ CRM в настройках и права (см. TUTORIAL.md вашей CRM). |
| Заявки не приходят на почту | Хостинг может блокировать `wp_mail`. Поставьте плагин SMTP (например WP Mail SMTP). |
| Кнопки не того цвета | Forestbyte → Настройки → Внешний вид → Цвет акцента → Сохранить. |
| Анимаций нет | Это нормально при медленном интернете/`reduced-motion` — виджеты работают и без них. |

## Приложение: как быстро собрать ZIP-архивы

В корне репозитория (Git Bash / терминал):
```bash
bash sites/wordpress/build-zips.sh
```
Скрипт создаст `sites/wordpress/dist/forestbyte.zip` и `forestbyte-starter.zip`,
готовые к загрузке через админку WordPress.
