Виджеты (кружки, сториз, лента соцсетей, FAQ, отзывы, попапы, счётчики) и форма-заявка
с отправкой лидов в CRM (Bitrix24 / amoCRM). Всё настраивается в админке.

== Description ==

Forestbyte добавляет на сайт готовые современные виджеты через шорткоды и подключает CRM:

* Форма-заявка → Bitrix24 / amoCRM (+ дубль на e-mail, антиспам honeypot)
* Сториз (как в Instagram), кружки-видео (как в Telegram)
* Лента постов из соцсетей, отзывы-слайдер, FAQ-аккордеон
* Счётчики, анимация появления при скролле, попапы
* Баннер согласия cookie (152-ФЗ / GDPR)

Внешний вид (цвет акцента, тема) настраивается в разделе «Forestbyte» админки.

== Installation ==

1. Загрузите папку `forestbyte` в `/wp-content/plugins/` (или установите ZIP через админку).
2. Активируйте плагин в меню «Плагины».
3. Откройте «Forestbyte» в админ-меню, задайте цвет и подключите CRM.
4. Вставляйте шорткоды виджетов на страницы (список — на странице настроек).

Подробный туториал: `sites/wordpress/TUTORIAL.md` в репозитории.
